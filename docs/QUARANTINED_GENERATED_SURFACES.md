# Quarantined generated surfaces

The old runtime initialized schemas at startup and mounted generic AI, public-export, warehouse, spreadsheet, and generated gap routes. `backend/src/server.js` mounts none of them. They remain only as provenance pending owner archive/delete decisions.

In particular, `gap_no_advanced_visualization_library_plotly_d3_deck_gl_on_backe.js` is not supported. The governed visualization workflow persists a permission-filtered versioned spec, query-plan approval, queued renderer command, receipts, retry/failure state, and acceptance tests; it does not use a generic chat response as a visualization backend.
